# DashScope TTS Demo

A browser-based text-to-speech playground for Alibaba Cloud's DashScope TTS APIs — Qwen3-TTS and CosyVoice.

## How to Run

Just open `dashscope-tts-demo.html` in your browser. No server needed — all API calls go directly from the browser to DashScope.

You'll need a [DashScope API key](https://dashscope.console.aliyun.com/) (paste it into the UI).

## Features

- **Qwen3-TTS** — Flash and Instruct Flash models, 48 voices, multi-language support (Chinese, English, Japanese, Korean, and more)
- **CosyVoice** — v3 Flash (88 voices), v3 Plus, and v3.5 models with custom/cloned voice support
- **Voice controls** — Volume, speed, and pitch sliders (CosyVoice)
- **Quick templates** — Pre-built prompts for food delivery, customer service, product ads, news, audiobook, and custom text
- **Instruct mode** — Natural language voice style instructions for Qwen3-TTS Instruct models
- **Debug tools** — View raw API response and cURL command
